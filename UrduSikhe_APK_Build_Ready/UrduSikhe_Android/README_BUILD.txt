URDU SIKHE - APK BUILD READY

This project wraps the supplied HTML in an Android WebView app.

OPTION 1 - Android Studio
1. Open this folder in Android Studio.
2. Use JDK 17.
3. Let Android Studio download/sync Gradle and Android dependencies.
4. Build > Build APK(s).
5. APK: app/build/outputs/apk/debug/app-debug.apk

OPTION 2 - GitHub Actions (no local Gradle installation needed)
1. Create a new GitHub repository.
2. Upload the contents of this project to the repository root.
3. Push to the main branch, or open Actions > Build Urdu Sikhe APK > Run workflow.
4. Open the completed workflow run.
5. Download the artifact named UrduSikhe-debug-apk.

App ID: com.rksolution.urdusikhe
App name: اردو سیکھے
Target SDK: 35
Min SDK: 23
The supplied HTML remains in app/src/main/assets/index.html.
